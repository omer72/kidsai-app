# Kidsit AI 1.0.17 release notes

Paste-ready store text only. Nothing here describes a feature that is not in the git history after 1.0.14 (`13e0f14`).

- Both stores: what parents can see that 1.0.14's notes did not say. 1.0.15 and 1.0.16 shipped the home "add a child" flow and the questionnaire card, and neither release added store text.
- Not mentioned, on purpose: the funnel now sends the full store version (`bc490be`). That is measurement only. The first three free answers, and the paywall after the first answer, were already in the 1.0.14 notes.

Character counts are JavaScript string length (UTF-16 code units), which is how both stores count. Limits: App Store 4000, Play 500.

Play upload reads the Play sections from `release-notes/play/en-US.txt` and `release-notes/play/he-IL.txt`. Those files are the text below, with no extra heading.

## App Store (English)

4000 character limit. This text is 480 characters.

```
You can add your first child on the home screen. A name and an age are enough: under 1, 1 to 12, or 13 or older. Then you can record or type what happened. The get-to-know-you questions no longer open on their own before you start.

After the first answer, Home shows a card offering those questions, so the next guidance fits that child. You can dismiss the card.

If you tap the hold-to-record microphone instead of holding it, the app tells you to hold the mic while you speak.
```

## Google Play (English)

500 character limit. This text is 336 characters.

```
Add your first child on the home screen. A name and an age are enough to start, and the get-to-know-you questions no longer open before you begin.

```
